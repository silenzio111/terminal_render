Markdown to terminal graphics

Read Markdown
without leaving the terminal.

mdx turns Markdown into high-resolution images using Typst and displays them through the Kitty graphics protocol. It also exports clean A4 or continuous PDFs.

View sourceExplore features

For people who live in a terminal but still care about typography.

mdx preserves a terminal workflow while giving long-form Markdown a readable, rendered presentation instead of asking you to mentally parse raw syntax.

Rendered pages

Convert Markdown to PNG with Pandoc and Typst, then display it in compatible graphics-capable terminals.

Interactive pager

Move page by page with familiar keys, jump to either end, and keep your focus inside the shell.

Watch while writing

When a source file changes, mdx re-renders it and preserves your reading position by progress.

PDF export

Export paginated A4 PDFs or one continuous long page using a pinned Typst paper template.

Font-aware

Use bundled or system fonts, with sensible CJK body-text and programming-font fallbacks.

Finder integration

A companion macOS app can register as a handler for Markdown files and export PDFs beside them.

Open a file. Render it. Keep reading.

Run mdx file.md for the interactive viewer, or mdx --pdf file.md for a PDF. Kitty, Ghostty, WezTerm, rio and Otty support the graphics protocol used here.
